“Orato — Giving your text a voice… literally.”

Orato is a smart mobile application designed to transform text and scanned content into speech using QR scanning and text-to-speech technology.

Built with Flutter, Orato focuses on accessibility, automation, and ease of use by converting digital content into audible output.

===========================================================================

Overview

Orato allows users to:

- Scan QR codes using the device camera

- Extract and process encoded information

- Convert text into speech

- Improve accessibility for reading and announcements

- The application is designed for educational environments, libraries, and general productivity use where quick text-to-audio conversion is needed.

- Current Implementation Status

- Orato currently uses the device’s built-in Text-to-Speech (TTS) engine.

===========================================================================

⚠️ Note:
A fully natural, AI-based human-like voice (such as Google Cloud TTS or ElevenLabs) has not yet been implemented. Future versions aim to integrate advanced neural voice synthesis for more realistic and expressive speech output.
